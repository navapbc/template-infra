# Template development

To get started working on the template, there are two chunks of context to
internalize. First, understanding the infrastructure code itself:

- Read about the [infrastructure's module
  architecture](/docs/infra/module-architecture.md) to learn how the
  architecture of the infrastructure code is designed and how the modules
  interact with each other.
- Read the [New developer docs](/infra/README.md#-new-developer) for using the
  template on projects, which covers tool installation and general guides for
  working with infrastructure that applies just as much to the template as to
  projects using the template.

Then for the template itself:

- Read the [design
  principles](/template-only-docs/template-technical-design-principles.md) to
  understanding overall philosophy to inform how to approach issues on the
  template.
- Read the [template development
  workflow](/template-only-docs/template-development-workflow.md) to understand
  how to develop and test changes to the template because working on the
  platform templates is unlike working on most other applications.
- Covered in other docs, but calling out again to read the [infrastructure style
  guide](/docs/infra/style-guide.md) to understand best practices for Terraform
  and shell scripts.
- Install and get familiar with the [Nava Platform
  CLI](https://navapbc.github.io/platform-cli/) tool and [how templates
  work](https://navapbc.github.io/platform-cli/reference/how-templates-work/).
